# 聊天：终端和网页

`rhine chat` 在终端中对话，`rhine web` 在浏览器中对话。两者共用同一批会话，在终端开始的会话可以在网页中继续。聊天记录、角色的笔记和摘要存放在 `data/` 下，每个角色一个 SQLite 数据库。

## 终端：`rhine chat`

```sh
uv run rhine chat dafeiyu                 # 进入与大肥鱼最近的会话
uv run rhine chat                         # 未指定角色时从列表中选择
uv run rhine chat dafeiyu -s trip         # 进入（或新建）名为 trip 的会话
uv run rhine chat dafeiyu --as u2 --name 小王   # 以另一个用户的身份发言
```

输入框的操作方式与常见的命令行 agent 一致：

| 按键 | 作用 |
|---|---|
| Enter | 发送 |
| Alt+Enter、Ctrl+J，或在行末输入 `\` 后回车 | 换行 |
| `/` | 弹出命令列表；Tab 补全命令和参数（角色、消息编号、文件路径） |
| `@` | 补全对话中角色的名字 |
| ↑ / → | 浏览输入历史 / 接受灰色的历史提示 |
| Ctrl+C | 生成中：中断本次回复（未完成的部分不保留）；输入时：清空输入；输入为空时连按两次：退出 |
| Ctrl+D | 退出 |

角色回复时，上方先显示思考摘要（可用 `/think` 隐藏）；使用工具（记笔记、翻记录、查资料）时单独显示一行。底部状态栏显示对话成员、私聊或群聊、使用的模型和本次运行的费用。

### 聊天操作

| 命令 | 作用 |
|---|---|
| `/quote <编号> <文字>`（`/引用`） | 引用一条消息并发言。编号见 `/history`，可用 Tab 补全 |
| `/recall [编号]`（`/撤回`） | 撤回自己的消息，默认为最后一条。与聊天软件相同，角色可能已经看到 |
| `/pat [角色]`（`/拍一拍`） | 拍一拍角色 |
| `/img <路径> [文字]`（`/图片`） | 发送图片，可附一句文字 |
| `/sticker <路径> [名字]`（`/表情`） | 发送表情包，名字相当于聊天软件为表情包提供的描述 |
| `/system <文字>` | 向角色下达系统指令（见下文） |
| `/retry` | 让最后发言的角色重新回复 |
| `/undo [n]` | 删除最后 n 条消息 |
| `/rewind [n]` | 回到之前某条消息之前；该消息由用户发送时，放回输入框以便修改后重发 |

多人对话中，在输入为空时按回车，可以让角色继续发言。

### 会话、用户和角色

| 命令 | 作用 |
|---|---|
| `/history [n]` | 本会话的消息及编号 |
| `/clear`（`/new`） | 新建会话，旧会话保留 |
| `/resume [编号]` | 回到以前的会话 |
| `/export [路径]` | 将本会话导出为 Markdown |
| `/name <昵称>` | 修改当前用户的昵称，身份不变 |
| `/as <ID> [昵称]` | 切换为另一个用户发言 |
| `/invite <角色>` | 邀请另一个角色加入对话 |
| `/kick <角色>` | 将邀请的角色移出对话 |
| `/instance [<角色>:<标签>]` | 列出持久化实例；带参数时创建实例 |

**私聊和群聊由人数决定。** 只有一个用户和一个角色时，每条消息都交给角色；对话中有更多参与者（`/as` 切换的用户发过言，或用 `/invite` 邀请了其他角色）时，每个角色按群聊方式自行判断是否接话：被 @、被引用或提到名字时必定回复，其余消息先经过 `reply_judge` 筛选（`/judge` 可关闭筛选）。

**多角色。** 被邀请的角色只能看到加入之后的消息，角色之间也能看到彼此的发言。为避免角色之间无休止地对话，用户每发一条消息，角色之间最多接力三次。重新进入该会话时，被邀请的角色一并恢复。

**持久化实例。** 默认情况下，每个会话的笔记相互独立。`<角色>:<标签>`（例如 `dafeiyu:cafe`）是同一角色包的一个实例，拥有独立的数据库，其笔记在它参与的所有会话之间共享。用 `/instance dafeiyu:cafe` 或 `rhine new dafeiyu:cafe` 创建，用 `rhine chat dafeiyu:cafe` 单独对话，或用 `/invite dafeiyu:cafe` 邀请进当前对话。

### 笔记、情景和系统指令

- **笔记**：角色自行记录需要记住的事，例如答应过的事、对方希望的称呼。`/memory` 查看笔记和对话摘要，`/forget <编号>` 删除一条；删除的笔记可以用 `rhine memory restore` 恢复。
- **情景**：`/scene <文字>` 记录本段对话之前发生的事，例如「昨晚两人一起看了烟花」。角色将其视为事实，并按自己的性格理解。`/scene` 不带文字时列出已有情景，`/unscene <编号>` 删除。
- **系统指令**：`/system <文字>` 向角色交代一条事实或规则，例如「现在下起了大雨」「这周说话都用敬语」。角色照此行事，但不会提及这条指令。

### 查看和设置

| 命令 | 作用 |
|---|---|
| `/status`（`/who`） | 当前用户、会话、对话成员、各任务的模型 |
| `/model [模型]` | 各任务的模型；带参数时，本次运行的回复改用该模型 |
| `/context` | 提示词各部分和聊天记录各占多少 token |
| `/stats`（`/cost`） | 本次运行的调用次数、token 用量和估算费用 |
| `/prompt` | 完整的 system prompt |
| `/think`、`/usage` | 开关思考摘要、每次回复后的用量显示 |
| `/judge` | 开关群聊筛选 |
| `/reload` | 重新读取角色包，无需退出 |

## 网页：`rhine web`

```sh
uv run rhine web                # 打开浏览器；未指定角色时打开上次使用的角色
uv run rhine web dafeiyu --port 8790 --no-open
```

启动时输出一个带 token 的链接，只有持有该链接的页面能够连接。默认只监听本机（`127.0.0.1`）；使用 `--host` 允许其他设备访问时，应只在可信网络中使用，且不应分享该链接。

网页提供终端版的全部功能：

- 左上角的角色卡可切换角色，其下是会话列表，「+」新建会话；左下角是当前用户的身份，点击可修改。
- 鼠标悬停在消息上（手机上点击消息）时显示操作：引用、撤回自己的消息、拍一拍、重新回复、复制、回到该消息之前。双击角色头像也可以拍一拍。
- 输入框中 Enter 发送，Shift+Enter 换行，`/` 弹出命令；支持粘贴或拖入图片，表情包按钮会要求填写表情包的名字。
- 角色回复时，思考摘要可以展开查看，工具调用单独显示一行；可以点击停止中断回复。
- 对话标题右侧可以邀请或移出角色；「⋯」菜单包含新建会话、重新回复、删除最后一条、导出 Markdown、重新读取角色包。
- 顶部的「笔记」「情景」「上下文」「提示词」在右侧打开面板，手机上从底部弹出。齿轮按钮打开设置：主题、回复模型（只对当前页面生效）、群聊筛选、用户身份、对话中的角色、本次运行的用量和快捷键。
- Ctrl+K 打开命令面板，可搜索命令、角色、会话和面板。主题有浅色、石墨和墨黑三种，默认跟随系统；主题和思考摘要的开关保存在当前浏览器中。

## 在服务器上管理角色

以下命令可以在网关运行时使用；角色包 ID 后可加 `:<标签>` 指定持久化实例：

```sh
uv run rhine memory list dafeiyu            # 笔记：编号、会话、关于谁、内容、日期
uv run rhine memory history dafeiyu         # 每一次记录、改写、删除、恢复
uv run rhine memory edit dafeiyu 12 "新内容"
uv run rhine memory rm dafeiyu 12           # 可用 restore 恢复；--purge 连同记录彻底删除
uv run rhine code dafeiyu                   # 一次性的系统指令码，见下文
uv run rhine instruction list dafeiyu       # 收到过的系统指令
uv run rhine instruction rm dafeiyu 7       # 撤销一条指令，效果等同于从未下达
```

**指令码**：聊天软件中无法使用 `/system`。此时先用 `rhine code <角色>` 生成一个一次性的码，再在聊天中发送以该码开头的消息，例如「码 现在开始下雨了」，码后的文字作为系统指令交给角色，这条消息不作为任何人的发言保存。码后的文字恰好是「撤销」时，撤销该会话最近的一条指令；恰好是「撤销全部」时，撤销全部指令。码默认 10 分钟内有效，使用一次即作废。

## 日志

`data/logs/` 下：

- `usage.jsonl`：每次模型调用一行，记录任务、会话、模型、token、估算费用和耗时。
- `<角色>-thinking.jsonl`：启用 `log_thinking` 时，记录每次回复的思考摘要和原文。
- 评测报告位于 `data/evals/`，导出的会话位于 `data/exports/`。
